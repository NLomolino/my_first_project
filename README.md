# Proyecto del brazo robótico

Repositorio de práctica del módulo M0.1 (Linux/WSL y Git) de mi ruta de mecatrónica.

## Entorno

Trabajo en WSL con Ubuntu. Ya venía usando esta terminal para PlatformIO con Arduino,
así que el manejo básico de archivos y carpetas ya lo tenía incorporado.

## PATH

el path es una variable que te indica el orden de los lugares que tenes que rivisar y el ls es la herramienta que estas buscando en uno de esos lugares.

## echo y el signo $

Echo lo que hace es imprimir el valor de la palabra que le indiquemos posteriormente a no ser que tenga el simbolo $. Si tiene ese simbolo lo que hace echo es imprimir lo que contiene esa variable

## Alias

el alias lo que hace es llamar a una accion. Lo que hicimos fue poner alias mecatronica='cd ~/proyectos_mecatronica' donde el "=" indica la accion a la que vamos a ponerle un alias. Al escribir la palabra "mecatronica" la terminal ejecuta ese comando entero
